# UAE Web-Dev Client Acquisition

Finding small UAE businesses with no website via Instagram/Google Maps, pitching them with a
personalized demo, building sites with Claude Code, and charging for them.

## Contents

- **`lead-tracker.xlsx`** — Leads tab (business info, status pipeline with color-coded
  dropdown, pricing, notes) and a Summary tab with live formulas (counts per status,
  conversion rate, revenue). Sample rows for the wedding vendor category are marked
  `SAMPLE - DELETE ME` — remove them before adding real leads.
- **`outreach/instagram-dm-template.md`** — paste-ready DM templates for demo-first outreach.
- **`docs/strategy.md`** — target categories, workflow, pricing, and the UAE unsolicited
  marketing rules to stay compliant with.
- **`docs/research-summary.md`** — supporting market research (SME website adoption, pricing
  landscape, what converts).

## Current stage

Category 1 (wedding vendors) — sourcing leads and starting outreach. See `docs/strategy.md`
for the full category order and next steps.
